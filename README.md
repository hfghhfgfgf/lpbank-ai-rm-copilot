## LPBank AI RM Copilot

Đây là ứng dụng web Streamlit đóng vai trò trợ lý ảo hỗ trợ nhân viên ngân hàng phân tích dữ liệu và tư vấn khách hàng.

## Tính năng chính
-Tổng quan khách hàng**: Hiển thị thông tin và biểu đồ chi tiêu.
-AI Customer Insight**: Phân tích hành vi và tín hiệu khách hàng.
-Next Best Offer**: Đề xuất sản phẩm phù hợp.
-RM Copilot Chat**: Trợ lý AI tích hợp mô hình ngôn ngữ lớn giúp trả lời câu hỏi chuyên sâu.

## Cài đặt và sử dụng
1. Cài đặt các thư viện cần thiết: `pip install -r requirements.txt`
2. Chạy ứng dụng: `streamlit run app.py`
